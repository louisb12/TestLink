## Integrate in minutes

<Tabs>
  <Tab title="Web">
    <CodeGroup>
      ```js index.js
      import { Link } from "@almedia/link-sdk";

      const link = new Link({
        container: "#link-root",
        theme: "midnight", // matches your brand automatically
      });

      link.render();
      ```
    </CodeGroup>
  </Tab>
  <Tab title="iOS">
    <CodeGroup>
      ```swift LinkViewController.swift
      import AlmediaLink

      let link = LinkView(theme: .midnight)
      view.addSubview(link)
      link.render()
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Android">
    <CodeGroup>
      ```kotlin MainActivity.kt
      val link = LinkView(context, theme = LinkTheme.MIDNIGHT)
      container.addView(link)
      link.render()
      ```
    </CodeGroup>
  </Tab>
</Tabs>

<Steps>
  <Step title="Install the SDK">
    One package, every platform above ships the same rendering core.
  </Step>
  <Step title="Point it at a container">
    Link mounts directly into whatever element or view you give it — no
    wrapper or iframe involved.
  </Step>
  <Step title="Pass your theme">
    `midnight`, `cream`, or a custom token set — the SDK repaints itself, you
    don't hand-roll CSS.
  </Step>
</Steps>
