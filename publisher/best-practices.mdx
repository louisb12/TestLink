## Why it lives somewhere else

Keeping one canonical copy means the guidance can never disagree with itself. This page is
deliberately a bridge, not a summary — a summary would drift out of date the first time the
guide is revised, and a reader would have no way of knowing which version they were looking
at.

<Warning>
  **Do not paste the guide's content into this page.** If something in it needs to live in the
  docs permanently, move it here and remove it there, so there is still exactly one copy.
</Warning>
