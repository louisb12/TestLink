Almedia Link reports through the MMP you already use. There is no separate dashboard to learn
and no SDK work in this section — everything here happens inside your own MMP, so it can be
completed before or in parallel with the engineering integration.


## What you need before you start

- **Access to your MMP dashboard** with permission to add a partner and change postback
  settings. In most teams this sits with growth, UA or marketing ops rather than engineering.
- **An Almedia contact.** Two of the three setups need something from us: Singular needs a
  Provider ID and API key, and Adjust asks you to send a screenshot of your event mapping back
  for review.

<Note>
  Each page is a transcript of the setup Almedia's team walks publishers through, screenshots
  included. Setting names and event names are reproduced exactly — if something in your
  dashboard is worded differently, ask rather than guessing at the nearest match.
</Note>

## Once it is live

Attribution is only useful if it is checked. The
