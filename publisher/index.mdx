This guide is for the commercial, product and design side of a Link integration. It covers
what to have ready before engineering starts, how to get the most out of the placement once
it is live, and how to wire up attribution through your MMP.

If you are writing the code, the [Technical Docs](/technical) are the place to be instead.

<Info>
  **A note for editors.** Every page in this section is plain MDX using only built-in
  components, so it can be edited safely in the Mintlify web editor. Please keep it that way —
  snippets and custom components do not work there, and adding one will break editing for
  everyone else on the team.

  The one exception is **Best practices**, which is a purpose-built interactive page owned by
  engineering. Edit that one in the repo, not the web editor.
</Info>
